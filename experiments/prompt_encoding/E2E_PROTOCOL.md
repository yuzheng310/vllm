## 边界和第一性推导

一次完整生成请求包含客户端序列化、HTTP、模板、分词、引擎排队、GPU
prefill/decode、输出处理和网络返回。缓存仅减少其中的历史分词。
既有强基线每 233 请求省约 0.121 秒，而此前 4B GPU 回放耗时约 166–180
秒：若所有其他条件不变且该节省完全落在关键路径，量级仅约 0.07%。
这只是量级估算，不是排队系统的严格上界，也不是端到端测量。

本轮必须真实加载 Qwen3-4B BF16、经过原生 Chat Completions HTTP 接口，
保留所有历史输入和记录的 22,046 个输出 token。后续 prompt 仍来自冻结
轨迹，输出不驱动真实仓库工具；工具间隔沿用 0.25 秒。因此结果称为
**单卡多轮推理端到端回放**，不能称完整 Agent 任务或 RL 训练加速。
不启动训练器、优化器、参考模型或多个 GPU 模型进程。

## 资源与唯一对照

- 单个常驻 GPU 服务，真实基础权重 Qwen/Qwen3-4B（不是训练 checkpoint）。
- 干净 v0.29.0 基础加本次三文件生产补丁，fastokens 0.3.1 双方开启。
- 4 条同时活动的轨迹；每条内部按轮依赖，固定任务顺序，完成后领取下一条。
  这是内存受限部署配置，不声称覆盖项目默认的更高并发。
- 固定 10 GiB GPU KV 池，max_num_seqs=8，max_num_batched_tokens=2048，
  max_model_len=40960，TP=1，BF16；APC、chunked prefill、async 开启，
  保留原生 cascade 自动选择。不开 CPU offload、swap 或量化。
- 约 7.5 GiB 权重 + 10 GiB KV，给激活、CUDA graph 和运行时留余量。
  启动前要求 GPU 无其他计算进程、至少 21 GiB 空闲、系统 MemAvailable
  至少 12 GiB；不释放别人的内存，不修改驱动/系统参数。
- OMP=1、Rayon=4、renderer workers=8，客户端和服务在同一主机 loopback。
  保留实际并发对调度的影响，不把固定序列分词测试替代吞吐实验。

## 执行与公平性

1. 记录 GPU/内存状态、权重/输入/源码 SHA，检查完整任务数与最大上下文。
2. 仅加载一次模型，预热最长输入和四请求并发（生成长度只在预热减小）。
   预热不计结果。计时阶段使用完整的记录输出长度、temperature=0、seed=42、
   ignore_eos=true，避免输出长度变化冒充加速。
3. 固定 A1/B1/B2/A2，A 为缓存关闭，B 为 16 MiB 新缓存。每轮开始前无
   活跃请求，清空 GPU APC，重建或禁用 CPU 缓存，保持同一个 KV 池和模型。
   开关通过仅存在于实验入口的 loopback 控制路由完成，不加入生产代码。
4. 每轮完整 48 轨迹 / 233 请求；包括所有冷首轮。除 0.25 秒工具间隔外
   不人为增加客户端延迟。启动、预热、控制操作、指标导出不计整批时间。
5. 测量客户端从发起完整请求到接收 SSE 结束的耗时、首个内容事件、统一
   批次起点到轨迹完成的时间。保存 vLLM 原生阶段指标和输入 token 摘要。
   额外摘要计算在双方相同，单独注明其开销未消除。
6. 核对输入 token 哈希、输出长度、完成率和缓存状态；输出文本保留摘要。
   默认 GPU 数值模式下即便输入相同，生成文本也未必逐字相同，必须报告。
7. 每 5 秒记录自建进程树 RSS、系统可用内存、GPU 用量/利用率/温度/时钟。
   新外部 GPU 进程、可用内存低于 4 GiB、OOM、接口错误或长度不符时停止
   本次自建进程并保留失败。启动最长 10 分钟，每轮最长 10 分钟。

## 分析和停止条件

- 主指标：整批完成耗时与轨迹/分钟，按 A1–B1、A2–B2 报告两组配对，
  同时给两组中位数的耗时变化。吞吐增长与耗时下降分别计算。
- 次指标：请求总延迟 P50/P95、客户端首内容时间、原生引擎 TTFT、轨迹
  批次完成 P95；分词累计时间只解释机制，不代替端到端指标。
- 检查 A1/A2、B1/B2 自身波动、实际 KV 池、抢占、GPU/内存曲线和输出差异。
  233 请求共享同一引擎且有时间依赖，不将其当成 233 个独立实验重复。
- 固定四轮后停止，不根据正负结果扫描并发、长度、后端或重复到显著。
  只有两次每组重复，不作窄置信区间或显著性承诺。若差异小于组内波动，
  明确报告“无法从本实验区分稳定收益与运行波动”。
- 全部原始结果、启动/失败日志、脚本、分析和决策归档并提交；不修改简历。
