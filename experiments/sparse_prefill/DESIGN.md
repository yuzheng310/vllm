# 从目标到引擎改动

## 目标：对完整轨迹中的动作打分

输入是一条已经生成好的轨迹，包含初始上下文、模型动作和工具返回。
调用方知道动作 Token 的位置集合 A，希望得到这些 Token 的条件概率。
本实验验证打分服务，不执行工具、不更新模型权重，也不假设训练已经采用该服务。

对输入 Token x[0:L]，因果模型得到 H[0:L, d]。目标位置 j 的概率为：

```text
z = H[j - 1] @ W_lm_head.T
log p(x[j] | x[:j]) = z[x[j]] - logsumexp(z[:])
```

所以目标位置 j 对应隐藏状态 j−1。可以删掉不需要的 LM-head 行，
却不能删掉前面工具返回的 Transformer 计算，也不能只在目标词上归一化。
这是功能成立的依据，不依赖某次性能测试碰巧更快。

## 在哪里少算

```mermaid
flowchart LR
    A[完整轨迹与动作位置] --> B[参数校验与请求传递]
    B --> C[原有分块 Prefill：Attention 与 MLP]
    C --> D[按当前块映射 j 到 packed hidden 行]
    D --> E[仅选择目标行进入原 LM head]
    E --> F[原有全词表归一化与 Top-K]
    F --> G[跨块收集：仅在 Prefill 完成后交付]
    G --> H[恢复原 Token 索引与空槽]
```

vLLM v0.29.0 的 V1 引擎包含 V2 GPU model runner。
这里的 `vllm/v1/` 是引擎目录名，不表示退回旧发行版。
实验固定 `VLLM_USE_V2_MODEL_RUNNER=1`，避免配置自动回退改变测量对象。

## 分块映射的推导

某请求已经计算 c 个 Token，本步调度 n 个 Token，在 packed batch 中从 q 开始。
本步可打分的目标位置为：

```text
j ∈ [c + 1, min(c + n, L - 1)]
packed_row(j) = q + j - c - 1
```

目标 j=c+n 可以由本块最后一行打分，虽然 x[j] 本身可能尚未进入
下一块 Transformer。这不违反因果关系：该分数只依赖 x[:j]。
输入轨迹已知，因此目标 Token ID 可以提前读取。

位置集合递增且唯一，二分查找即可定位当前块的交集。
每个请求独立保存位置和中间结果；批次排序通过已有 idx mapping 对齐。
最后一个块可能没有动作，仍然必须交付前面累积的结果。

## 为什么不继续扩大范围

- 首版不添加新的候选词集合协议，复用已有目标 Token/Top-K 语义。
- 保留原输出索引，减少调用方改造与跨进程协议变化。
  代价是仍有 O(L) 空槽，不能宣称整个输出只有 O(|A|)。
- CUDA 单卡、完整 decoder-only 文本请求是明确的首版边界。
  LoRA、推测解码、流式输入和其他 runner 的状态映射未验证时拒绝请求。
- 不引入近似 KV 或概率算法，因此不需要用训练收敛来掩盖概率语义变化。

## 收益的边界

设词表大小 V，隐藏维度 d，全量所需投影行 S，动作行数 |A|：

```text
可删除的 LM-head 乘加 FLOPs ≈ 2 (S - |A|) d V
新请求耗时 = 原 Transformer 时间
           + 选行后的 LM-head 与概率处理
           + 选行/参数/结果恢复开销
           + 原有必要生成与传递开销
```

少算工作是可证明的，实际耗时下降还取决于矩阵形状、带宽、CPU 输出成本等。
因此先验证行数，再比较完整调用耗时；不把静态 FLOPs 或行数换算成测速结果。
“足以写进简历”也要求如实写清支持边界和测量条件。

## 最便宜的充分证据

| 风险 | 最小证据 |
| --- | --- |
| j 与 j−1 错位、批次重排串请求 | CPU 行路由测试，使用不同请求的可辨识数值 |
| 块边界或空尾块漏结果 | CPU 连续调度多块，精确核对最终位置 |
| 只对选中的词归一化 | 固定 logits 的真实 GPU 测试，对照 FP32 全词表 log-softmax |
| BF16 GEMM 形状差异 | 与固定 logits 测试分离，记录模型级逐位置误差 |
| 抢占后重复或漏交付 | 复用上游强制抢占测试，核对位置且确认实际发生抢占 |
| 只优化了调用端过滤 | worker 内统计实际进入概率投影函数的行数 |
| 测量 hook 制造性能差异 | 诊断与正式计时分开，计时时恢复原函数 |
| 较弱基线夸大收益 | 原版与改后关闭功能、FlatLogprobs、连续后缀和逐轮方案 |
