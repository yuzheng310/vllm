# 多轮 Agent 的动作位置稀疏 Prefill 打分

这是个人 fork 中的 vLLM 二次开发与教学实验，不是已合并的上游功能。
目标是把调用者已经知道的动作位置传到 GPU runner，在 LM head 之前
筛选需要的 hidden-state 行，保持完整因果上下文及原来的概率定义。

## 为什么这个改动属于引擎开发

完整轨迹中的工具返回仍然要进入 Attention 和 MLP。
优化的边界是 Transformer 最终 hidden states 到词表分数之间：
只投影动作行，并在分块与异步结果传递后恢复正确的原始 Token 位置。
在 Python 调用端计算全部分数后再丢弃，不满足这个目标。

已有内核负责全词表归一化、目标 Token 和 Top-K 提取。
本项目复用这些实现，不把已有 kernel 包装成新算法。
